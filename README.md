Resturant Menu & Order Management System

This project is a simple restaurant order management system built using Python core data structures such as dictionaries, lists and nested structures.

The program performs different operations on the provided menu, inventory and sales log data.



Task 1 – Explore the Menu
- Display the menu grouped by category
- Show item price and availability
- Calculate:
  - Total number of items
  - Number of available items
  - Most expensive item
  - Items priced under ₹150

Task 2 – Cart Operations
Simulates a customer ordering system:
- Add items to cart
- Remove items from cart
- Update item quantity
- Prevent adding unavailable items
- Print final order summary with GST calculation

Task 3 – Inventory Tracker
- Demonstrates deep copy of inventory using `copy.deepcopy()`
- Deducts stock after order placement
- Generates reorder alerts when stock goes below reorder level

Task 4 – Sales Log Analysis
- Calculates total revenue per day
- Finds the best-selling day
- Identifies the most ordered item
- Adds a new day to the sales log
- Prints a numbered list of all orders
